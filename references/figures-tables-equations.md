# Figures, tables, equations and callouts

## Audit both files and what readers see

Map each figure and table to its embedded or separate version, caption,
panel letters, callouts, source-data item and supplementary counterpart.
If there are both separate and embedded copies, compare the actual content
and version, not just the filenames. Apply the journal's current rules for
embedded versus separate artwork, file types, dimensions, panel limits,
captions, tables and supplements. A rule for accepted production artwork
does not automatically apply to a review PDF.

Inspect artwork and table content at the intended display size. Record file
type, pixel dimensions, placement dimensions and applicable colour space
or resolution where observable. For raster images, assess effective resolution
from pixels and intended physical size, not a metadata DPI tag alone.
A vector file can contain low-resolution raster elements. Mark resolution
**无法检查** if the artwork or placement size needed to measure it is missing.
Check contrast, greyscale or colour-vision readability, legibility and
accessibility against the applicable rule or audience need. An unreadable
preview or extraction can make label verification **无法检查**. A legibility
defect observed in the actual submission artwork can be **未通过** for that
check. Avoid generic
thresholds, fixed figure fonts or a universal table style.

Check that the figure or table can be read with its caption, legend or notes.
Inspect axes, units, groups, denominators, colour or marker meaning, uncertainty
and statistical notation where relevant. Use the shortest sufficient key.
See [abbreviation review](abbreviation-review.md) for standard codes, technical
symbols, study-specific definitions and text versus embedded-label differences.
Check figure claims against the displayed evidence and compare tabulated and
reported values at equivalent precision.

When appropriate, inspect maps for relevant attribution, sources, labels,
projection, geographic conventions and licensing. Check clearance
identifiers or sensitive locations only under applicable rules or context.
For image provenance,
permissions, modifications and generative use, use
[integrity and availability](integrity-and-availability.md). Flag visible
anomalies or missing records with exact evidence. A visual review alone does
not establish authentic or unmanipulated source imagery.

## Numbering and callouts

Inventory displayed and textual labels for figures, tables, equations and
supplementary items. Trace each callout to the correct target and compare
first-citation order where the journal requires it. Check missing and
duplicate targets, wrong panels, broken or stale fields, and whether the
reference points to the correct analysis. Inspect linked prose across the
main file, supplement, legends and separate artwork. Preserve intentional
separate numbering systems, shared supplement numbering and references to
unlabelled display equations when permitted.

## Equations, variables and units

Inspect equations as rendered. XML or extracted text can collapse subscripts,
fractions, Greek characters, superscripts and mathematical grouping. Check
which objects genuinely need equation numbers. For each important variable
or parameter, check a clear definition, units or dimensionless status,
indices and scope. Check sign, scale, weighting, normalisation, uncertainty,
ranges, boundary conditions and assumptions as relevant to the analysis.
Compare symbols and definitions across the manuscript, supplement, tables,
figures and any available code or method specification. Scientific consistency
can be checked from a document without claiming the equation was recomputed.
