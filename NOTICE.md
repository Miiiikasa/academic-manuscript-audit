# Provenance and redistribution

Version 2.0.0 reorganised the original academic-English protocol (v1.1.0)
into a general whole-manuscript workflow. Version 2.1.0 adds paragraph necessity,
argument quality, cross-passage language comparison and an editorial assessment.
Version 2.2.0 adds an abbreviation and first-use audit for text and display items.
Version 2.2.1 improves caption concision and flags scientific label conflicts.
Version 3.0.0 adapts that protocol as academic-manuscript-audit, with journal
intake, evidence hierarchy, submission package checks, integrity and reference
verification, and two read-only reporting templates. Version 3.1.0 adds the
recent-publication benchmark and restores follow-up review. It also adds
revision-stage package checks and aligns the status vocabulary and templates.
Version 3.1.1 clarifies conditional declaration counts and missing required
files. Version 3.1.2 makes full-audit intake and user confirmation explicit.
The public release is maintained at
[Miiiikasa/academic-manuscript-audit](https://github.com/Miiiikasa/academic-manuscript-audit).
